### 1. Bối cảnh và đội ngũ

- **STAFF_FSC:** thực hiện phiếu (viết mã, kiểm thử, mở PR), tự kiểm theo checklist và gộp PR của mình theo mục 13 của tài liệu quy trình.
- **KCS_FSC:** kiểm độc lập (đủ phiếu chưa, 8 điều kiện), gộp PR khi đủ, kiểm lại sau gộp; có thể được giao vai "CEO TRỰC" khi CEO nghỉ.
- Tài liệu gốc: `docs/PHOI_HOP_CEO_STAFF.md` (mục 11 quy trình v2, mục 12 nhịp tự động, mục 13 bàn giao STAFF làm cả hai vai) và Issue **#56** (quy trình và các bình luận bàn giao). Đọc trước khi làm.

### 4. Tám điều kiện gộp PR
1. Phạm vi đúng phiếu (đối chiếu từng mục "Việc phải làm" và "Tiêu chí đạt" ở Issue phiếu).
2. CI Windows xanh 3/3 (chất lượng mã, bố cục Word qua PDF Ubuntu, `build` Windows) **trên đúng head của PR**.
3. Kiểm thử đơn vị đạt, không giảm, không bỏ qua thêm.
4. Bản in: 206 tài liệu giống từng byte so với `main` (nếu phiếu không nhằm đổi bản in).
5. Có kiểm thử mới **đỏ trước, xanh sau** chứng minh thay đổi.
6. `renderer/index.html` được dựng lại và nằm trong commit.
7. Không bình luận treo; không xung đột.
8. Các sửa kiểm thử/e2e cũ chỉ đổi chỗ đọc chữ hoặc bước thao tác theo quyết định bố cục, **không nới điều kiện kiểm**.

### 5. Cách nghiệm thu trên `main` (lệnh thật)
Dùng git worktree ngoài thư mục làm việc; `node_modules` dùng chung bằng symlink. Chạy bằng `NODE_OPTIONS=` (rỗng); Electron cần `xvfb-run -a`.
```
git fetch origin main <nhánh-PR>
git worktree add --detach <thư-mục>/wt-pr origin/<nhánh-PR>
git worktree add --detach <thư-mục>/wt-main origin/main
ln -sfn <repo>/node_modules <thư-mục>/wt-pr/node_modules   # và wt-main
cd wt-pr
NODE_OPTIONS= npm run -s build:html && git status --short    # trống = renderer dựng đúng
NODE_OPTIONS= node scripts/test.js 2>&1 | grep -E "^ℹ (tests|pass|fail|skipped)"
NODE_OPTIONS= xvfb-run -a node scripts/so-ban-in.js --root <wt-main> --out main.json
NODE_OPTIONS= xvfb-run -a node scripts/so-ban-in.js --root <wt-pr>   --out pr.json
NODE_OPTIONS= node scripts/so-ban-in.js --so main.json pr.json         # phải ra 206 giống, 0 khác
NODE_OPTIONS= xvfb-run -a node scripts/e2e-all.js <tên bộ> ... --out <thư-mục-báo-cáo>
```
- Luôn so bản in với **trạng thái ngay trước PR cùng ngày** (mục lục có ngày sinh).
- Đọc diff các tệp kiểm thử bị sửa. Nếu PR đổi giao diện: xem ảnh trước/sau trong `docs/anh-phieu-*/` (1366×768 ở 100/125/150% và 1920×1080), đối chiếu mục tiêu của phiếu.
- Cuối một đợt: chạy workflow **Build Windows installer** bằng `workflow_dispatch` trên `main` **không có `release_tag`** để có CI Windows đầy đủ (kiểm thử đơn vị, 120 bộ e2e, smoke bộ cài, cài đè từ v2.3.0) trên đúng commit.
