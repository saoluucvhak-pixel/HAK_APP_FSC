## 8. CÁCH LÀM ĐÃ CHẠY TỐT VÀ CÁC BẪY

**Cách làm:** chia việc cho agent chuyên biệt (công cụ Agent, `subagent_type` general-purpose; nếu cần cô lập dùng worktree riêng do bạn tạo trước bằng `git worktree add`), mỗi agent một vai: *coder* (test đỏ trước, sửa tối thiểu cho xanh), *tester e2e*, *reviewer chỉ đọc*. Phạm vi tệp độc quyền, không chồng nhau; dặn rõ agent coder **không chạy e2e và không push** (bạn chạy e2e và đẩy). Một agent soát độc lập trên toàn diff trước khi mở PR (soát vòng này tìm được 3 lỗi P2 thật). Tự chạy lại unit, e2e, bản in sau mỗi báo cáo. Khi đưa lệnh cho agent, ghi tường minh: đường dẫn worktree, nhánh, quy tắc cứng, tệp được sửa, kết quả cần báo (SHA, lệnh, số thật).

**Chạy e2e (luôn ở 1024×768, mỗi lần MỘT Electron; không chạy việc nặng song song):**
```bash
flock -w 900 /tmp/hak-e2e.lock env -u NODE_OPTIONS HAKQN_CLOSE=discard xvfb-run -a -s "-screen 0 1024x768x24" \
  node scripts/e2e-all.js <tên-bộ ...> --out <thư-mục-ngoài-repo>      # không có tên: chạy cả ≈139 bộ, ≈ 30 phút
# bộ nâng cấp từ v1.4.33 cần mã nguồn cũ:
HAKQN_ROOT_CU=/tmp/v1433 flock -w 900 /tmp/hak-e2e.lock env -u NODE_OPTIONS HAKQN_CLOSE=discard xvfb-run -a -s "-screen 0 1024x768x24" \
  node scripts/e2e-all.js cai-de --no-skip --out <thư-mục>
```
Chạy nền để không bị ngắt: bọc trong `( … ; echo done > <tệp>.done ) &` và kiểm tệp kết quả; **tiến trình e2e chết nếu phiên làm việc bị khởi động lại** (đã xảy ra: dừng ở 43/139), khi đó chạy lại từ đầu. Kết quả cuối có dòng `Tổng: N/N bộ đạt`.

**Bẫy:**
- Khóa `/tmp/hak-e2e.lock` có thể bị tiến trình `Xvfb` thừa giữ: triệu chứng `flock` treo hàng chục phút. Kiểm `fuser -v /tmp/hak-e2e.lock`; chỉ kill `Xvfb` thừa khi chắc không còn e2e nào chạy. Luôn viết đủ đường dẫn khóa (`flock -w N /tmp/hak-e2e.lock env -u NODE_OPTIONS …`), thiếu sẽ tạo tệp rỗng tên `env`.
- Hook cuối lượt báo "có commit chưa đẩy" / "có tệp chưa theo dõi": đẩy nhánh được giao; thư mục `.claude/worktrees/` là của agent, loại bằng `echo ".claude/worktrees/" >> .git/info/exclude`, không commit.
- Agent tạo worktree tách từ `main`, không phải nhánh hiện tại: tự kiểm `git log` và đưa về đúng nền trước khi làm. Hai agent cùng sửa một thư mục làm e2e đang chạy bị lẫn phiên bản mã: đừng sửa mã trong thư mục đang chạy e2e.
- `git checkout -- <tệp>` trên thay đổi chưa commit có thể bị chặn; dùng bản sao lưu tệp rồi chép lại.
- `tests/e2e-all.test.js` bắt buộc mọi `scripts/e2e-*.js` đều khai báo trong `SUITES` của `scripts/e2e-all.js` (khi gộp nhánh: hợp hai danh sách).
